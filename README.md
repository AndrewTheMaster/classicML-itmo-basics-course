# classicML-itmo-basics-course

Материалы по курсу "Основы ML" (ИТМО): лабораторные работы, EDA и датасеты.

## Ноутбуки

- `з1.ipynb` — задание 1: Работа с данными
- `л1.ipynb` — лабораторная работа 1: кластеризация
- `л2.ipynb` — лабораторная работа 2: ассоциативные правила
- `л3.ipynb` — лабораторная работа 3: SVM для детекции P300 (MOABB)
- `л4.ipynb` — лабораторная работа 4: градиентный бустинг (HAR UCI)
- `eda_coursework.ipynb` — EDA coursework: исследование закономерностей в датасете Student Alcohol Consumption

## Данные и дополнительные файлы

В репозитории также лежат исходные датасеты (`.csv`, `.xlsx`).
Они используются в разных заданиях и ноутбуках.

## Запуск

1. Создайте и активируйте виртуальное окружение Python 3.10+.
2. Установите зависимости из ячеек ноутбуков (`%pip install ...`) или вручную.
3. Откройте ноутбуки в Jupyter/Cursor и выполните ячейки сверху вниз.

Для `л4.ipynb` рядом с ноутбуком должна быть папка `UCI HAR Dataset`
(или поменяйте путь `base_dir` внутри ноутбука).
