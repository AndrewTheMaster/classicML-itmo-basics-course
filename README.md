# classicML-itmo-basics-course

Лабораторные работы по курсу "Основы ML" (ИТМО).

## Содержимое

- `л3.ipynb` — ЛР 3: SVM для детекции P300 (MOABB)
- `л4.ipynb` — ЛР 4: Градиентный бустинг (HAR UCI)

## Как запустить

1. Создайте и активируйте виртуальное окружение Python 3.10+.
2. Установите зависимости из ячеек ноутбуков (`%pip install ...`).
3. Откройте ноутбуки в Jupyter/Cursor и выполните ячейки сверху вниз.

Для `л4.ipynb` рядом с ноутбуком должна быть папка `UCI HAR Dataset`
(или поменяйте путь `base_dir` внутри ноутбука).
